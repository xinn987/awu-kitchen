# 整体 UI Review 报告（2026-08-29）

范围：全部 11 个页面 + 快速收录面板 + 导入流程，基于开发者工具全量截图（shots/ 目录）。
结论先行：**问题不在某个元素画错了，而在于没有一套被贯彻到底的视觉秩序**。详情页是唯一接近"有品味"的页面，应被确立为全 App 的基准语言；其余页面各说各话。

---

## 一、系统性问题（"粗糙感"的根源）

### 1. 容器语言分裂：卡片流 vs 开放纸面
两种体系并存，没有使用规则：

- **卡片流**：食谱库、家庭页（成员卡/邀请卡/免责卡）、设置页、编辑页步骤——万物皆白卡（白底 + 1px 边 + 极淡阴影）
- **开放纸面**：详情页（细分隔线 + 留白分节）、食谱选项页、编辑页其他区块

同一个 App 里，家庭页像 iOS 设置，详情页像杂志。阴影淡到几乎不可见（0 2rpx 6rpx @5%），白卡浮在米色纸上显得"没设计完"而不是"克制"。

**建议**：确立详情页的"开放纸面 + 细分隔线"为默认容器；白卡片只保留给"列表中可点击的实体"（食谱卡、废纸篓条目），家庭/设置改为分组 + 分隔线。

### 2. 橙色通胀：强调色失去强调能力
一屏之内橙色同时承担：FAB、激活筛选 chip、三个"+ 添加"文字按钮、必填星号、提示文字、四角星、主食材色块文字、导入提示边框与警示文字、设置页图标底块、当前版本时间线圆点……
结果是**没有任何橙色元素是特殊的**。"家庭页的生成并复制"大按钮和"添加食材"小字链接同样醒目。

**建议**：给橙色定预算——每屏最多 1 个主操作 + 少量语义标记（四角星）。筛选激活态改墨色/描边，"+ 添加"统一降级为 ink-2 中性文字按钮，设置页图标去底色块。

### 3. 说明文字泛滥：产品像说明书
逐页统计灰色辅助文字：选项页 4 段（页面说明 + 组说明 + 空态 + 共享说明）、家庭页 2 段大段（邀请说明 3 行 + 权限免责 3 行）、导入页 2 段、编辑页 3 处（单选说明、主食材说明、常用标签）、废纸篓 1 段、详情页脚注 1 段。
单看每段都有道理，合起来**页面 30% 是免责声明和操作指导**，且全部是同一种"灰色小字"，视觉上是一层噪音。

**建议**：砍 50%。法律/隐私必要的保留（导入页隐私说明）；操作指导降级为"首次出现的 toast"或字段 placeholder；家庭页免责压缩成一行。

### 4. 排版无标尺：三种 section 标题、衬线随机出现
- section 标题三种写法：详情/编辑 = 灰色小字 + 图标；选项页 = 32rpx 衬线 600 深色 + 描述行；设置页 = 22rpx 加字距灰标签 + 白卡
- 衬线字体出现在：页面大标题、食谱名、成功关键内容、选项页组标题、设置页版本号"v0.1.11"——但食材、步骤、评论、chips 全是黑体。**衬线不是体系，是点缀**
- 字重 400/500/600 混用无规则

**建议**：标题只留一档中间规格（建议 30-32rpx，衬线，用于一切 section 标题，替换图标+灰字方案）；衬线规则定为"标题与正文中的'经验内容'"；字重两档制 500/600。

### 5. 图标气质与产品不符
Feather 风格线性图标（zap 闪电、shopping-bag 购物袋、list 列表、tag 标签）是 SaaS 工具的视觉词汇，放在"家庭辅食手账"上没有温度；区块标题图标 28rpx 灰色，信息量趋近于零但每行都有。皇冠挤在"（你）"旁边。设置页图标有品牌色圆角底块，全 App 独一份。

**建议**：要么去掉区块标题图标（文字本身足够），要么换一套更圆润/手绘感的图标并统一线宽；设置页底色块取消。

### 6. 没有食物感
去掉照片后，这个 App 看不出和"吃"有关：无第二色彩（食物的绿/黄/棕）、类型徽章"汤羹"是灰色的、空态是纯文字、列表卡没有图片位。色彩系统 = 米色 + 白 + 橙 + 灰，功能上没错，气质上是笔记工具。

**建议**：列表卡有主图时展示小缩略图；辅食类型徽章按类型低饱和着色；空态配简单手绘风元素；这是一笔投入不大但感知最强的"去粗糙"改动。

### 7. 双重反馈体系
`wx.showToast`（原生黑框）与自研 `app-toast`（深色胶囊）并存；编辑页校验错误用原生、保存成功用页面跳转 toast；历史页用原生。确认弹窗已统一（confirm-panel），toast 没有。

**建议**：全部收敛到 app-toast；同时把 navbar 左上文案规则统一（现状"返回/取消/食谱库"三种并存）。

## 二、逐页问题清单

### 食谱库（r-01 / r-03 / r-15）
1. 激活筛选 chip 是实心橙块，页面最响的元素不是内容而是筛选器；chip 内计数让一行更挤
2. 待补卡片用斜体 + 虚线边框，斜体在中文里显得廉价
3. 卡片没有图片位——家庭食谱列表零食物图像（见系统性问题 6）
4. FAB 悬浮在最后一张卡的内容上，列表底部 padding 不足
5. 快速收录菜单（x3）：两个入口卡，第一个橙边橙底"邀请式"高亮让第二个看起来像禁用

### 详情页（r-05 / d1-d3）——基准页面，问题最少
1. 底部「评论 / 复制 / 完善食谱」中"复制"的意图不明（复制给谁？为什么值得一级按钮）
2. 「修订记录」以下划线小链接藏在 meta 行，与它的功能重量不匹配
3. 食材无用量显示"—"（土豆 —），观感像缺数据
4. 页脚：footnote 一行 + 红色"移入废纸篓"孤字，收尾仓促
5. 步骤缩略图（新版）整体成立

### 编辑页（h1-h3 / g1-g2）
1. 三种内容容器混在一屏：纸面深底输入框、白色步骤卡、描边 chips——每种单独成立，同屏节奏打架
2. "zap 闪电"图标给"成功关键"语义牵强
3. 步骤卡片头部：序号与右侧工具之间大片空白，视觉重心失衡；六张连续白卡重复感强
4. 添加食材有三条路径同屏（建议 chips、添加按钮、输入框），加上"全家常用"标签行，食材区是全页最吵的区块
5. 导入提示（import-notice）边框 + 洗底 + 警示列表三层强调，在编辑表单顶部过于隆重

### 家庭页（r-12）
1. 四张白卡堆叠 + 卡外裸"设置"行，容器语言在单页内自相矛盾
2. 邀请说明 3 行小字像产品使用文档；免责声明 3 行包成卡片最重
3. 成员卡内皇冠图标与"（你）"挤在一起

### 设置页（r-14）
1. 图标品牌色圆角底块——全 App 仅此页有，语言孤立
2. 版本号用 46rpx 衬线展示"v0.1.11"，数字穿衬线效果差且过度设计
3. 页面 2/3 空白，与家庭页功能有重叠（可考虑合并或补充内容）

### 食谱选项页（r-07）
1. 4 段灰色说明文字管理 6 个 chips（系统性问题 3 的极端案例）
2. 页面下半 60% 空白
3. 移除 × 24rpx 偏小，命中区域依赖外扩 padding

### 修订记录（r-17）
1. 每条修订内容完全相同却都展开完整快照，4 块重复的"该版本的成功关键 1. 要用陈年老酒1"纸深底块——页面在惩罚滚动
2. 修订说明全是"更新食谱内容"，无 diff 感知（老问题，仍未解决）
3. "恢复此版本"是裸文字链接 + rotate 图标，与全 App 按钮语言脱节

### 评论页（r-19）
1. 结构干净，是第二好的页面
2. 空态一行文字；"最旧"措辞仍未改
3. 排序条与内容之间关系弱（两个灰 chip 悬空）

### 废纸篓（r-11）
1. 顶部说明 + 空态一行字，整页 90% 空白——空态是品牌感最差的页面

### AI 导入页（x2）
1. 「提交识别」禁用态是白底浅灰字，浮在米色背景上几乎不可见——用户不知道按钮在哪
2. 提示卡片 + 隐私说明两段灰字，同样说明文字问题
3. 「食谱图片 0/9 张」计数与标题挤在一起，层级不清

### 快速收录（x3 / r-04）
1. 两步流程的交互本身是好的
2. 第二步"正式存入 / 暂存待补"双按钮关系清晰
3. sheet 标题 600 黑体 vs 页面标题衬线，弹层与页面像两个产品（联动系统性问题 4）

### Onboarding
未能自动化截取（已有成员身份会重定向），需清缓存或新设备人工核对。

## 三、需要真机确认的疑点

1. 多张截图左缘出现上一页内容的"渗色"细条（页面转场动画被截帧）——疑似模拟器截图时机问题，需真机滑动确认是否真的存在转场残影
2. Skyline 渲染下 textarea 的 auto-height 与键盘避让（编辑页底部步骤卡 + 吸底保存栏 + 键盘三者的遮挡关系）需要真机验证

## 四、整改优先级建议（未实施，待拍板）

| 优先级 | 事项 | 影响 |
| --- | --- | --- |
| P0 | 容器规则统一（开放纸面为默认，白卡只给列表实体）：重做家庭页、设置页 | 消除最大的"两个产品"感 |
| P0 | 橙色预算制 + "+ 添加"按钮统一降级 | 让主操作重新醒目 |
| P1 | section 标题统一为一档衬线标题，去区块图标；字重两档制 | 排版秩序 |
| P1 | 说明文字砍半（家庭页、选项页、导入页、编辑页） | 密度与气质 |
| P1 | 食物感注入：列表卡缩略图、类型徽章着色、空态品牌化 | 感知最强的一笔 |
| P2 | toast 统一 app-toast；navbar 文案规则；"最旧"→"最早" | 一致性收尾 |
| P2 | 修订记录 diff 摘要 + 恢复改按钮；导入页禁用按钮可见性 | 功能可懂性 |
| P2 | 图标体系评估（统一线宽或更换圆润风格） | 气质升级，工作量较大 |
| 待定 | 详情页"复制"按钮去留；归档入口位置（前轮遗留） | 需产品决策 |

## 五、一句话总结

这套设计的底子（暖纸色 + 衬线 + 橙色 + 细分隔线）是对的，详情页证明了它成立；粗糙感来自**秩序没有立法**：容器、橙色、标题、图标、说明文字各自为政。先立规矩，再逐页执行，品味问题会解决大半。
